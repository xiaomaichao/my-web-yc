# 占彦超 · 个人作品集

React 19 + Vite 8。单页作品集，最大版心 1700px；针对 PC 展示设计，同时适配窄屏。

## 本地运行

双击「启动预览.cmd」，保持窗口运行，然后访问 http://127.0.0.1:5173/ 。

在已配置 Node.js 22.13+ 和 pnpm 的终端中，也可执行：

- pnpm install
- pnpm dev
- pnpm build（生成 dist 文件夹）
- pnpm preview（检查正式构建）

## 内容与素材

- src/content.js：个人资料、6 段工作经历、项目说明、能力文案。
- src/App.jsx：五个页面模块及作品弹窗。
- src/styles.css：版式、字体、响应式和动效。
- public/assets：52 张 WebP 图片与 4 段 MP4 视频，来自 F:\个人资料。

简历中的 16 年经验按原文保留，52 件图片 / 4 段视频为本次素材计数，并非职业生涯项目总数。作品组标题与描述根据提供的素材整理，未添加不存在的客户、年份或项目指标。

未提供真人头像，关于我模块当前采用本人创作的角色作品，并在页面注明。收到照片后可替换该模块图片。

首版为本地预览，未发布到互联网。原始简历和素材保留在原位置。背景视频默认静音，支持暂停；系统开启减少动态效果时不自动播放。邮箱与电话号码来自提供的简历。

## 新增 UI 与游戏视频

精选作品增加合成游戏 8 张、肉鸽游戏 23 张 UI 设计稿；src/ui-assets.json 保存标题和原图尺寸。三支 720 × 1280 角色活动视频已单独展示，支持播放、音量与全屏，同一时间只播放一支作品视频。UI 弹窗内点击图片或「查看原图」可打开完整尺寸图片。
